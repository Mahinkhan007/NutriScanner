## 🚀 Overview

**NutriScanner** is a cutting-edge Flutter app that empowers users to make healthier, smarter supplement choices by simply scanning a product's **barcode**. It’s designed especially for **gym-goers, athletes, and health-conscious users**, delivering personalized and intelligent nutrition recommendations.

Powered by **OpenAI**, **OpenFoodFacts**, and **Firebase**, NutriScanner not only provides full nutritional breakdowns — it **talks to you** and guides your health journey.

## ✨ Features

- 📷 **Barcode Scanner** – Instantly scan gym supplements and fitness food items.
- 🧬 **Nutritional Analysis** – Get detailed data from **OpenFoodFacts API**.
- 🧠 **OpenAI Integration** – Understand product benefits, safe dosages, side effects, and receive similar product suggestions.
- 💬 **AI Chatbot** – Ask questions about the product; get instant, intelligent replies.
- 🔐 **Authentication & User Profile** – Login/signup via Firebase Auth.
- 📊 **BMR-Based Personalization** – Calculates user’s **Basal Metabolic Rate** and suggests tailored fitness products (e.g., fat burners for obese users).
- ☁️ **Firestore Storage** – Stores user preferences and scan history for better suggestions.

## 📦 How It Works

1. **User logs in** and enters body details (weight, height, gender, age).
2. App calculates **BMR** and tailors the homepage product suggestions.
3. Scan a **barcode** using the camera.
4. NutriScanner fetches data via **OpenFoodFacts API**.
5. Sends product details to **OpenAI API** for analysis.
6. Returns:
   - Nutritional values
   - Safe dosage (if applicable)
   - Pros and cons
   - Similar products
7. User can chat with the **AI assistant** to ask any follow-up questions.

## 🔐 Authentication & Storage

- 🔐 **Firebase Auth** – Email/Password sign-up and login.
- ☁️ **Cloud Firestore** – Stores:
  - User profile info & BMR
  - Previous scans
  - Tailored product data
